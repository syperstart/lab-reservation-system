# 智能实验室预约系统 · 预约状态与取消/审核问答

## Q1：预约状态有哪几种？
- 问法：预约状态 / 状态有哪些 / 状态含义
- 答案：共四种：待审核、已通过、已拒绝、已取消。

## Q2：「待审核」是什么意思？
- 问法：待审核 / 提交后没反应 / 审核中
- 答案：表示预约已提交、正在等待管理员审核，此时预约尚未生效。

## Q3：审核通过是什么状态？被拒绝呢？
- 问法：审核结果 / 通过 / 拒绝 / 审核后变成什么
- 答案：审核通过后状态变为「已通过」，预约生效；审核不通过时状态变为「已拒绝」。

## Q4：怎么取消预约？
- 问法：取消预约 / 怎么撤销预约 / 不想约了
- 答案：进入「我的预约」，找到该预约，点「取消」并确认即可。

## Q5：哪些状态的预约可以取消？
- 问法：能不能取消 / 什么状态能取消
- 答案：只有「待审核」和「已通过」的预约可以取消。「已拒绝」「已取消」的预约不能再取消。

## Q6：为什么某条预约没有「取消」按钮？
- 问法：取消按钮没了 / 不能取消 / 没有取消按钮
- 答案：因为该预约状态不是「待审核」或「已通过」（例如已拒绝、已取消），这类状态不支持取消。

## Q7：预约被拒绝了怎么办？
- 问法：被拒绝 / 审核没通过 / 拒绝了怎么办
- 答案：被拒绝的预约不能恢复，需要重新提交一次预约；提交前留意拒绝原因并调整时间或设备。

## Q8：被拒绝能看到原因吗？
- 问法：拒绝原因 / 为什么被拒
- 答案：管理员拒绝时可以填写原因，可在预约详情/备注中查看；如仍不清楚，请联系管理员。

## Q9：提交预约后多久能审核？
- 问法：多久审核 / 什么时候通过 / 审核要等多久
- 答案：审核由管理员人工处理，系统不保证固定时间。可在「我的预约」中随时查看状态变化。

## Q10：已经「已通过」的预约还能再审核吗？
- 问法：重复审核 / 再审核 / 已通过的还能改吗
- 答案：不能。只有「待审核」状态的预约可以审核，已审核过的记录不能再重复审核。

## Q11：我的预约是空的 / 看不到自己的预约？
- 问法：我的预约没有 / 看不到预约 / 预约列表为空
- 答案：请确认两点：① 当前登录的是提交预约的那个账号；② 状态筛选条件是否把记录过滤掉了（把状态设为「全部」再查一次）。
