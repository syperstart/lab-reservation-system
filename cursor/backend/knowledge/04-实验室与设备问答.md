# 智能实验室预约系统 · 实验室与设备问答

## Q1：在哪里查看实验室？
- 问法：实验室在哪 / 实验室列表 / 看有哪些实验室
- 答案：学生端左侧菜单进入「实验室列表」，以卡片形式展示可预约的实验室。

## Q2：实验室卡片上显示哪些信息？
- 问法：卡片信息 / 实验室显示什么
- 答案：实验室名称、位置、容量（可容纳人数）、开放时间、设备数量，以及「查看设备」和「预约」两个按钮。

## Q3：怎么搜索实验室？
- 问法：搜索实验室 / 按名称查 / 找实验室
- 答案：在「实验室列表」顶部的搜索框输入实验室名称，点查询即可筛选。

## Q4：实验室状态「启用 / 停用」是什么意思？
- 问法：启用 / 停用 / 实验室状态
- 答案：「启用」表示可以预约；「停用」的实验室不会出现在可预约列表中，也不能预约。

## Q5：设备状态「正常 / 维修」是什么意思？
- 问法：设备状态 / 维修 / 正常
- 答案：「正常」表示设备可用，预约时可以选择；「维修」表示设备不可用，预约时不能选择。

## Q6：设备列表里有哪些信息？
- 问法：设备信息 / 设备字段 / 设备有哪些内容
- 答案：所属实验室、设备名称、图片、型号规格、数量、状态。

## Q7：为什么实验室列表里没有某个实验室？
- 问法：找不到实验室 / 实验室不见了 / 没有这个实验室
- 答案：可能有两种原因：① 该实验室被设为「停用」；② 被搜索条件过滤掉了（清空搜索框再查一次）。

## Q8：在哪里看实验室的开放时间？
- 问法：开放时间 / 几点开门 / 营业时间
- 答案：实验室卡片上会显示「开放时间」，例如 08:00 - 20:00。预约时间段必须在开放时间内。

## Q9：设备「数量」是什么意思？
- 问法：设备数量 / 有几台
- 答案：表示该实验室下这种设备的数量。

## Q10：设备图片看不了？
- 问法：设备图片 / 图片显示不出来
- 答案：部分设备可能未上传图片，此时显示占位图属正常现象；可在设备列表中点击图片查看大图（有图时）。
