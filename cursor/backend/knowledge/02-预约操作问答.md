# 智能实验室预约系统 · 预约操作问答

## Q1：怎么预约实验室？
- 问法：怎么预约 / 如何预约 / 预约流程 / 我要预约实验室 / 预约步骤
- 答案：登录后进入「实验室列表」→ 选择要预约的实验室 → 点「预约」→ 填写预约日期、开始时间、结束时间、用途（设备可选）→ 提交。提交后状态为「待审核」，等管理员审核通过后预约才生效。

## Q2：预约时要填哪些信息？
- 问法：预约要填什么 / 预约表单有哪些字段
- 答案：实验室（自动带入）、设备（可选）、预约日期（必填）、开始时间（必填）、结束时间（必填）、用途（必填）。

## Q3：可以不选设备吗？
- 问法：设备必须选吗 / 只约实验室 / 不选设备
- 答案：可以。设备是可选字段，不选表示只预约实验室整体，不指定具体设备。

## Q4：怎么看某个实验室有哪些设备？
- 问法：查看设备 / 实验室有哪些设备 / 设备列表
- 答案：在「实验室列表」中找到该实验室，点卡片上的「查看设备」按钮即可查看。

## Q5：为什么预约提交不了 / 提交失败？
- 问法：预约失败 / 提交不了预约 / 预约报错
- 答案：常见原因有六种：① 预约日期早于今天；② 开始时间晚于或等于结束时间；③ 所选时间超出实验室开放时间；④ 该实验室同一日期时间段已被预约（冲突）；⑤ 所选设备不属于该实验室或处于维修状态；⑥ 实验室已停用。对照提示调整后重新提交即可。

## Q6：为什么提示「该时段已被预约」？
- 问法：时间段冲突 / 已被预约 / 约不了这个时间
- 答案：同一实验室、同一日期内，你的时间段与已有预约重叠。换一个时间段或换一个实验室再约。

## Q7：能预约今天之前的日期吗？
- 问法：选不了日期 / 过去的日期 / 日期为什么是灰的
- 答案：不能。预约日期不能早于今天，日期选择器会自动禁用今天之前的日期。

## Q8：提示「开始时间必须早于结束时间」怎么办？
- 问法：时间顺序不对 / 开始晚于结束
- 答案：把开始时间调到结束时间之前，例如 09:00 开始、11:00 结束。

## Q9：为什么提示超出开放时间？
- 问法：开放时间 / 不在营业时间 / 超出开放时间
- 答案：预约时间段必须落在实验室的开放时间内（实验室卡片上会显示开放时间，如 08:00 - 20:00）。

## Q10：一个人可以同时预约多个实验室吗？
- 问法：能约多个吗 / 多个预约 / 同时约两个实验室
- 答案：可以，只要每个预约都满足校验规则即可。

## Q11：设备下拉是空的 / 选不了设备怎么办？
- 问法：设备选不了 / 设备下拉没有选项 / 没有设备
- 答案：说明该实验室当前没有可选的设备，可以直接不选设备，只预约实验室。

## Q12：提交成功后在哪里看？
- 问法：提交后在哪看 / 预约记录 / 我的预约在哪
- 答案：在「我的预约」中查看，刚提交的预约状态为「待审核」。

## Q13：预约时间段怎么选比较合适？
- 问法：时间段怎么填 / 开始结束时间怎么选
- 答案：开始时间要早于结束时间，并且整个时段都在实验室开放时间内；尽量避开已被预约的时段。
