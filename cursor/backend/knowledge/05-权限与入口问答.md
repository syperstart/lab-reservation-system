# 智能实验室预约系统 · 权限与功能入口问答

## Q1：学生能做哪些操作？
- 问法：学生功能 / 学生能做什么 / 学生权限
- 答案：学生可以查看实验室列表、查看设备、提交预约、在「我的预约」中查看和取消预约、维护个人信息、使用 AI 智能助手。

## Q2：管理员能做哪些操作？
- 问法：管理员功能 / 管理员能做什么 / 管理员权限
- 答案：管理员可以管理实验室（增删改查）、管理设备列表、审核预约、管理账号（查看所有账号及详情）、维护个人信息。

## Q3：学生能看到实验室管理、设备管理、预约审核吗？
- 问法：学生能看到管理页面吗 / 学生没有管理菜单
- 答案：不能。实验室管理、设备列表管理、预约审核、账号管理都是管理员专属功能，学生的菜单里不会显示。

## Q4：管理员能预约实验室吗？
- 问法：管理员能预约吗 / 管理员预约
- 答案：预约功能面向学生；管理员主要负责维护实验室/设备数据和审核预约。

## Q5：找不到某个菜单或页面怎么办？
- 问法：菜单没了 / 找不到某个功能 / 页面去哪了
- 答案：左侧菜单是根据当前账号的角色动态显示的。请确认登录账号的角色：学生看不到管理员菜单，管理员看不到学生菜单。另外确认是否被浏览器缩放或窗口宽度影响。

## Q6：访问某个页面提示无权限怎么办？
- 问法：无权限 / 没有权限 / 403
- 答案：说明当前账号角色不具备该页面权限。学生请使用学生端功能；如需管理功能，请用管理员账号登录。

## Q7：「账号管理」在哪里？
- 问法：账号管理 / 用户管理在哪 / 查看所有账号
- 答案：管理员的左侧菜单中有「账号管理」，可查看系统内所有账号列表，并支持按账号/姓名搜索、按角色和状态筛选、查看账号详情。

## Q8：AI 智能助手能问什么？
- 问法：AI助手能干什么 / 能问什么 / 助手有什么用
- 答案：可以咨询预约流程、取消规则、各功能怎么用、常见问题怎么处理等规则类问题。AI 无法查询实时数据，具体实验室、设备、开放时间、预约记录请到对应页面查看。

## Q9：个人信息在哪里进入？
- 问法：个人信息 / 个人中心 / 我的资料
- 答案：点击右上角头像/用户名，选择「个人中心」即可进入个人信息页。
