# 智能实验室预约系统 · 答疑知识库索引

> **用途**：本目录是 AI 助手的「答疑知识库」，内容为**问答对（Q&A）**，用于提升回答准确率。
> **使用原则**：AI 回答时应优先依据本知识库的问答；知识库未覆盖的问题，要明确说明不确定，并引导用户去对应页面查看或联系管理员，**不要编造**。

| 文件 | 覆盖的答疑范围 |
|---|---|
| `01-登录与账号问答.md` | 登录失败、注册、忘记密码、个人信息、头像上传 |
| `02-预约操作问答.md` | 怎么预约、填什么、提交失败的各种原因、时间段与设备选择 |
| `03-预约状态与取消审核问答.md` | 待审核/已通过/已拒绝/已取消、怎么取消、被拒绝怎么办 |
| `04-实验室与设备问答.md` | 实验室列表、搜索、开放时间、设备状态与信息 |
| `05-权限与入口问答.md` | 学生/管理员能做什么、菜单找不到、无权限、AI 助手能问什么 |
| `06-提示与报错对照.md` | 各种提示语/报错对应的原因与处理办法 |

每条问答由「问法（同义提问）+ 答案」组成，便于按语义匹配。
