# 智能实验室预约系统 · 提示与报错对照

> 用途：用户看到某条提示时，AI 可据此快速解释原因并给出处理办法。

| 用户看到的提示 / 现象 | 原因 | 处理办法 |
|---|---|---|
| 账号或密码错误 | 账号不存在或密码不正确 | 确认账号是登录账号（非姓名）、密码正确、无多余空格 |
| 账号已被禁用 | 账号状态被设为禁用 | 联系管理员启用账号 |
| 登录已失效，请重新登录 | 登录凭证过期或无效 | 重新登录 |
| 请求参数校验失败 | 提交的字段缺失或类型不对 | 检查必填项是否都填了、格式是否正确 |
| 无权限访问 | 当前角色没有该功能权限 | 学生用学生功能；管理功能需管理员账号 |
| 该时段已被预约 | 同实验室同日期时间段重叠 | 换时间段或换实验室 |
| 预约日期不能早于今天 | 选了过去的日期 | 选择今天或之后的日期 |
| 开始时间必须早于结束时间 | 开始时间晚于/等于结束时间 | 调整起止时间顺序 |
| 超出实验室开放时间 | 所选时段不在开放时间内 | 按卡片上的开放时间重新选择 |
| 设备不属于该实验室 | 选择的设备不属于当前实验室 | 重新选择该实验室下的设备 |
| 设备状态不可用 | 设备处于维修状态 | 换一个正常状态的设备或不选设备 |
| 实验室不存在 / 已停用 | 实验室被删除或停用 | 刷新实验室列表，换一个启用中的实验室 |
| 预约记录不存在 | 记录已被删除或 id 不对 | 刷新「我的预约」列表后重试 |
| 当前状态不支持审核 | 该预约不是「待审核」状态 | 只有待审核的预约可以审核 |
| 审核状态错误 | 审核参数不是通过/拒绝 | 使用页面上的通过/拒绝按钮操作 |
| 文件不能超过 5MB | 上传文件过大 | 换一张小于 5MB 的图片 |
| 不支持的文件类型 | 上传了非图片或非白名单格式 | 使用 jpg / png / gif / webp |
| 网络错误，请稍后重试 | 网络异常或后端未启动 | 确认后端服务已启动，稍后重试 |
| 页面空白 / 打不开 | 前端报错或路由异常 | 强制刷新页面；仍有问题联系管理员 |
| 列表「暂无数据」 | 当前没有符合条件的记录 | 清空筛选条件或先创建数据 |

## 补充说明
- 所有业务提示都会以统一格式返回（包含 code、message），页面会直接弹出 message 内容；
- 若提示内容不在上表中，说明该问题需要具体排查，可联系管理员并提供操作步骤与提示原文。
