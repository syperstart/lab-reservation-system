# 智能实验室预约系统 · 登录与账号问答

## Q1：怎么登录系统？
- 问法：怎么登录 / 登录入口在哪 / 如何进入系统 / 登录方式
- 答案：打开系统登录页，输入「账号」和「密码」，点「登 录」。登录成功后进入系统首页。管理员示例账号为 `admin`，密码 `admin`。

## Q2：为什么提示「账号或密码错误」？
- 问法：登录失败 / 密码错误 / 登不进去 / 账号不存在
- 答案：说明账号不存在或密码不正确。注意「用户名」要填**登录账号**（如 `admin`、`student01`），不是真实姓名；并确认大小写、是否多输入了空格。

## Q3：为什么提示「账号已被禁用」？
- 问法：账号被禁用 / 无法登录但密码对 / 账号停用
- 答案：该账号状态被设为「禁用」。请联系系统管理员在账号管理中启用该账号。

## Q4：忘记密码怎么办？
- 问法：忘记密码 / 密码丢了 / 重置密码
- 答案：系统不提供自助找回密码。请联系系统管理员重置密码。

## Q5：怎么注册账号？
- 问法：注册 / 新用户注册 / 创建账号
- 答案：在登录页点「没有账号？去注册」，填写账号、密码（可选填姓名）后提交，注册成功后可返回登录页登录。

## Q6：注册时提示「用户名已存在」？
- 问法：用户名已存在 / 注册失败 / 账号重复
- 答案：说明该账号名已被占用，换一个账号名重新注册即可。

## Q7：注册出来的账号为什么是学生？能注册管理员吗？
- 问法：注册角色 / 怎么成为管理员 / 注册后是学生
- 答案：自助注册的账号一律是「学生」角色。管理员账号由系统预置，不开放自助注册。

## Q8：刷新页面需要重新登录吗？
- 问法：刷新要登录 / 登录状态丢失 / 保持登录
- 答案：不需要。登录凭证（token）保存在浏览器中，刷新页面后仍保持登录状态。

## Q9：提示「登录已失效，请重新登录」怎么办？
- 问法：登录过期 / 登录失效 / token 失效
- 答案：登录凭证已过期或无效，重新登录一次即可。

## Q10：个人信息里哪些可以改？
- 问法：修改个人信息 / 改名字 / 改邮箱 / 改手机号 / 能改角色吗
- 答案：可以修改「名称、邮箱、手机号、头像」；「账号」和「角色」是只读的，不能自行修改。

## Q11：怎么上传/更换头像？
- 问法：换头像 / 上传头像 / 头像怎么改
- 答案：进入「个人信息」，点击头像区域选择图片上传，支持 jpg、png、gif、webp，大小不超过 5MB。上传后点「保存修改」生效。

## Q12：头像上传失败怎么办？
- 问法：头像传不上去 / 文件太大 / 不支持的文件类型
- 答案：检查两点：① 图片格式是否为 jpg/png/gif/webp；② 大小是否超过 5MB。不满足时换一张符合条件的图片即可。
